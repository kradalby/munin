## Project Overview

Munin is a static gallery generator written in Swift that processes photo albums into a JSON API with responsive images. The application reads a folder structure, extracts metadata from images (EXIF, location, keywords, people), generates multiple resolutions for responsive display, and outputs a structured JSON API.

## Architecture

The codebase follows a clean Swift Package Manager structure:

- **Sources/Munin/**: Command-line interface (`main.swift`)
- **Sources/MuninKit/**: Core library containing the gallery generation logic
  - `Gallery.swift`: Main orchestration and build process
  - `Album.swift`: Album and photo model structures
  - `Photo.swift`: Photo processing and metadata extraction
  - `Utils.swift`: Utility functions
  - `Statistics.swift`: Gallery statistics generation
  - `Locations.swift`: Geographic data processing
  - `Keyword.swift`: Keyword extraction and organization
  - `Templates/`: Stencil templates for code generation
  - `Autogenerated/`: Generated Swift code for protocols

The application processes images using:
- **VIPS** (via swift-vips): Image processing and resizing
- **SwiftExif**: EXIF metadata extraction
- **libiptcdata**: IPTC metadata handling
- **libgd**: Additional image processing (Linux)

## Configuration

Munin uses JSON configuration files (default: `munin.json`) with settings for:
- Input/output paths
- Image resolutions to generate
- JPEG compression quality
- File extensions to process
- People detection
- Concurrency settings

## Key Technical Details

- **Concurrency**: Uses GCD with configurable semaphores to limit concurrent image processing
- **Progress Tracking**: Real-time progress animations during image processing
- **Diff Processing**: Compares input vs existing output to only process changed content
- **Code Generation**: Uses Sourcery to auto-generate protocol conformances
- **Cross-platform**: Supports both macOS and Linux with platform-specific linking

## Processing Pipeline

1. Read input directory structure and discover images
2. Compare with existing output (if present) to generate diff
3. Process changed images: resize, compress, extract metadata
4. Generate JSON metadata for albums and photos
5. Build keyword and people indexes
6. Generate location data and statistics
7. Clean up unused files

The application is designed for incremental processing - only changed content is regenerated on subsequent runs.
